## Day 1: Academic Personal Website- Sarah Borni

## About the Project
This repository contains my personal academic website, created using **GitHub Pages**. The website presents my academic background, research interests, professional experience, skills, and personal hobbies.

## Tools and Technologies
- **GitHub** – Repository management and version control.
- **GitHub Pages** – Hosting and publishing the website.
- **Jekyll** – Static site generator.
- **Markdown** – Writing and organizing website content.
- **HTML** – Adding and customizing images and page elements.
- **CSS / SCSS** – Customizing the website's appearance, colors, typography, and layout.

## Steps Taken to Create the Website

1. **Created a GitHub repository** to store the website files and manage the project.
2. **Enabled GitHub Pages** to publish the website online.
3. **Configured the website** using the `_config.yml` file, including the website title, description, and Jekyll theme.
4. **Created the main webpage** in `index.md` using Markdown and HTML.
5. **Added personal content**, including:
   - About Me
   - Academic Background
   - Research Interests
   - Laboratory and Research Experience
   - Technical Skills
   - Hobbies and Personal Interests
   - Contact Information
6. **Uploaded personal images** to the `assets` folder, including a profile picture and a hobbies illustration.
7. **Customized the website design** using a custom SCSS stylesheet (`assets/css/style.scss`), including typography, heading styles, colors, and background design.
8. **Published and updated the website** through GitHub Pages whenever changes were committed to the repository.
